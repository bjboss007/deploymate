# Vendored fonts

- **IBM Plex Mono** — SIL Open Font License 1.1 (IBM).
- **Schibsted Grotesk** — SIL Open Font License 1.1 (Schibsted Media Group),
  latin subset 400/500/600/700, fetched from Fontsource
  (`@fontsource/schibsted-grotesk`) on 2026-10-02.

Both are served from `/static/fonts/` so the UI makes no external requests.
`ibm-plex-sans-*.woff2` are no longer referenced by the stylesheet.
