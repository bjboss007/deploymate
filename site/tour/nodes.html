A node sees everything that runs on it

Its owner can read the code, environment variables and data of whatever you place there. Only add machines whose owner you trust.

Connect a machine
  1. On the machine, install Docker and Tailscale (signed in to the same tailnet as this server), and create a user that may use Docker.
  2. Add this server's key to that user's ~/.ssh/authorized_keys.
  3. Add the node here, using the machine's Tailscale address. If you reach it through an SSH alias or a tunnel instead, also give the private address its apps' ports are reached at.
