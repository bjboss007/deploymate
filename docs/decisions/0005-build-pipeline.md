# 0005 — Build pipeline: git CLI + ssh-keygen deploy keys + buildx CLI

- **Date:** 2026-08-28
- **Status:** accepted

## Context

Git deploys must clone private repos, build images, and keep artifacts for
rollback. The Docker Go SDK's `ImageBuild` is non-streaming and
feature-limited; deploy keys must work with every SSH client.

## Decision

1. **Clone with the git CLI** (`clone --filter=blob:none --depth 1`,
   pinned-commit fetch + checkout when a SHA is given), authenticating via
   a per-repo ed25519 **deploy key** in a 0600 temp file with
   `GIT_SSH_COMMAND` (`IdentitiesOnly=yes`, `BatchMode=yes`,
   `StrictHostKeyChecking=accept-new`).
2. **Deploy keys are generated by the real `ssh-keygen` binary**, not
   crypto libraries. Rationale: `x/crypto/ssh`'s `MarshalPrivateKey`
   output in the pinned version was rejected by `ssh-keygen -y` itself
   ("invalid format"); the CLI's output is correct by construction.
3. **Build with `docker buildx build --progress=plain --load`** via
   `exec.Command`, streaming every line to the database + dashboard.
   Dockerfile-first; Nixpacks/Railpack is a planned fallback for repos
   without one (improvements).
4. Images are tagged `deploymate/apps/<slug>:<deployment_id>` and loaded
   into the local daemon (no local registry needed on one host). Rollback
   = redeploy a kept tag; retention keeps the newest 5 per app.

## Consequences

- Build output streams line-by-line over SSE with zero SDK wrestling.
- `--load` keeps the single-host story trivial; a registry or
  `cache-from/to` appears only when remote builders arrive.
- Requires `ssh-keygen`, `git`, `docker`, and the buildx plugin on the
  host — all installed by `bootstrap.sh`.
- Local-only images (e.g. `dbprobe:latest` in tests) must never be
  pulled unconditionally: `ImagePull` hits the registry even when the
  image exists locally, so callers check `HasImage` first.

## Alternatives

- **SDK `ImageBuild`** — protobuf-only progress, no streaming; buildx CLI
  is what Coolify/Dokploy shell out to as well.
- **go-git / libgit2** — no SSH agent-free deploy-key story as simple as
  the CLI's.
